## Run Locally

**Requirements:** Node.js 18.17+ (Node.js 20 LTS recommended) and npm.

```bash
# 1. Clone the repository
git clone https://github.com/ParamjeetSlathia/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open the local URL shown in the terminal (usually http://localhost:3000).

To create a production build:

```bash
npm run build
npm start
```
